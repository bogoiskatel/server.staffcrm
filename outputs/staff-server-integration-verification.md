# STAFF SERVER: перевірка локальної інтеграції

Дата: 2026-10-05. Джерело — робоча локальна копія STAFF CRM; база приймача — server.

Авторизований ручний запуск cli/collect.php через перевірений локальний TLS на 8766 збирає API з 8765. API без Bearer-ключа відповідає 401. Ключі й конфіги залишаються поза Git.

Для періоду 2026-10 отримано одну установку «Церква Сіон»: 119 членів, 12 домашніх груп, 1 людина на дисципліні. Хрещення за жовтень і за 2026 рік — 0; приєднання за 2026 рік — 0. Вибуття — 0 за відомими датами; 16 недатованих записів позначено як неповний підсумок. Показники не підмінюють невідомі дати вигаданими.

Повторні збори залишили один знімок установки за місяць. Тести перевіряють захист статистики, координат, назви та зашифрованого контакту від старих відповідей. Контактний токен зберігається зашифрованим libsodium sealed-box; перевірено розшифрування тестового токена.

Пройдено 17 перевірок семантики, перевірки контракту collector, ізольовані тести MariaDB, регресії API дисципліни/дат/межі місяця, тести дублювання й шифрування та HTTP-авторизації/CSRF. Усі тести розміщені в tests.

У браузері перевірено дашборд, реєстр, деталі знімка, маркер, меню користувача та випадаючий вибір UA/EN. CSS і меню використовують оригінальний STAFF CRM theme.

Постійний розклад cron не встановлено: для пробного запуску виконується та сама CLI-команда. Після перезапуску/перебудови демо CRM слід повторити python3 local/connect-crm.py.
